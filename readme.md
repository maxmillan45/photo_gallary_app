
# Photo Gallery Web Application

A full-featured photo gallery web application built with Django that allows users to view, interact with, and manage a collection of photos, portraits, and artworks.

## Features

### User Authentication and Registration
- User registration with unique username, email, and password
- Secure login/logout functionality
- Password hashing and security best practices

### User Profile Management
- Dedicated profile page for each user
- Update profile information (bio, profile picture, phone, location)
- Change password functionality
- View personal photo collection

### Photo Gallery
- Browse photos with titles and descriptions
- View detailed photo information
- Filter photos by tags/categories
- Responsive grid layout for photo display

### User Interactions
- Like and dislike photos
- Real-time like/dislike updates without page refresh
- View like/dislike counts on each photo

### Responsive Design
- Mobile-friendly interface
- Optimized for desktop, tablet, and mobile devices
- Built with Tailwind CSS

## Technical Requirements

- Python 3.x
- Django 4.2.7
- PostgreSQL (or SQLite for development)
- Pillow (image processing)
- Tailwind CSS
